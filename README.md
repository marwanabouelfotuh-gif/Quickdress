# Quickdress

Quickdress is an iOS app that photographs a user's wardrobe once, then recommends a complete outfit from those clothes every morning, matched to the day's weather and calendar. It turns a 10-minute decision into a 10-second confirmation, using only clothes the user already owns.

The app is built with SwiftUI and SwiftData. Wardrobe data, photos and calendar information stay on the phone. Recommendations come from a rule-based scorer first, with an on-device Core ML model and an opt-in Gemini step behind the same interface.
