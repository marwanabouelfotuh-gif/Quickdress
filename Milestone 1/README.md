# Milestone 1: Scoping, Requirements and Architecture

Each document is provided as a Word file and as a PDF.

| File | What it is |
|---|---|
| `Milestone 1.docx` / `.pdf` | The full submission in one document: cover and links, Part A (Requirements Specification), Part B (Design Specification) and Part C (presentation outline) |
| `Quickdress_Requirements_Specification.docx` / `.pdf` | System overview, users and stakeholders, product backlog (22 functional and 11 non-functional requirements), scope and sprint plan, use cases, and global and social considerations |
| `Quickdress_Design_Specification.docx` / `.pdf` | High-level architecture (UML component diagram), components and interfaces, sequence diagrams, quality attributes, patterns, class diagram, and feasibility and risks |
